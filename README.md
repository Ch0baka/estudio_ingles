# English Study Portal

React + Vite + Tailwind CSS study app for modal verbs and vocabulary.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to GitHub Pages

The Vite base path defaults to `/estudio_ingles/`, matching this folder name.

```bash
npm run deploy
```

If your GitHub repository has a different name, run the build/deploy with:

```bash
VITE_BASE_PATH=/your-repo-name/ npm run build
npm run deploy
```
