# English Study Portal (`estudio_ingles`)

Plataforma interactiva de estudio de inglés desarrollada con **React 18**, **Vite 6** y **Tailwind CSS**. Diseñada para guiar el aprendizaje progresivo de gramática, comprensión lectora, comprensión auditiva, vocabulario y verbos conjugados.

🌐 **Sitio en Producción (GitHub Pages):** [https://ch0baka.github.io/estudio_ingles/](https://ch0baka.github.io/estudio_ingles/)

---

## 📚 Contenido Incluido

- **Unit 1 · Verbos Modales:** Teoría y 10 ejercicios interactivos sobre *must*, *mustn't*, *have to*, *don't have to* y *should*.
- **Unit 2 · Hábitos y Pronombres:** Comprensión de referencia pronominal, metas y 18 ejercicios prácticos sobre rutinas saludables.
- **Unit 3 · Pasado Simple (Was / Were):** Guía completa de uso y 24 ejercicios interactivos guiados.
- **Unit 3 · Preparación de Examen:** 26 preguntas divididas en 8 objetivos curriculares clave, incluyendo:
  - Comprensión lectora (*Reading* de Emma).
  - Comprensión auditiva con audio nativo (*Listening* de Lucas).
  - Familias de palabras (*teach/teacher*, *write/writer*, *help/helpful/helper*).
  - Distinción entre fragmentos y oraciones completas.
- **Verbos Bilingües (232 verbos):** Catálogo interactivo de 116 verbos irregulares y 116 verbos regulares con conjugaciones (infinitivo, pasado, participio), traducción y buscador en tiempo real.
- **Tarjetas de Vocabulario (49 tarjetas):** Definiciones en inglés y español, traducción y oraciones de ejemplo contextuales.
- **Sistema de Temas:** Modo claro / oscuro y 6 paletas de colores de acento persistidas en `localStorage`.

## 🛠️ Comandos de Desarrollo y Operación

### Instalación de dependencias
```bash
npm install
```

### Servidor local de desarrollo
```bash
npm run dev
```

### Bucle de Verificación (Integridad de contenido)
```bash
npm run lint
# o también:
npm test
```

### Compilación para producción
```bash
npm run build
```

### Despliegue en GitHub Pages
```bash
npm run deploy
```
